# Trial.12 materialized-portfolio review

The retained report and failure scene are under
`.hima-tmp/ui-trial-0.3.0-trial.12/`. Pack 5.1.7 installed correctly and the
first generation generated 40 distinct `G0001` Cells. The Run stopped before
commercial EDA because the next stage matched those physical candidate ids
against pre-namespace portfolio ids.

The report proposed either exposing the deterministic selector's verdict to the
Workshop or relaxing the exact-match gate. Replaying the actual artifacts
showed that neither change is necessary. After identity reconciliation, the
strict selector accepts the Workshop's complete 40-candidate delta. The four-id
difference cited in the report compared the earlier whole-pool ranking with the
Workshop's later eligible-pool choice; that is not the gate's unit of analysis.

The accepted correction is therefore limited to the existing stage adapter.
Trial.13 must establish the first real `design-mapping-timing-evaluation`
success, then proceed through cumulative Library freeze, commercial adoption,
physical comparison and at least one later generation when the 5% Goal remains
unmet.
