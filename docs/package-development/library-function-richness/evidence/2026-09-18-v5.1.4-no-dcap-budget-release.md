## Trigger and root cause

Trial.8 Run `run-28580186-19d0-4a65-a604-c68e1392637f` inserted 33,215 fixed DCAP
instances. The retained stage facts reached 0.9772 post-CTS and 0.9963 final effective occupancy;
the Site log reported 2,857,352 geometry DRC markers. The fixed checkerboard scaled with core area,
so floorplan expansion did not remove its occupancy fraction.

The visible Campaign Agent also left its final Job absent from `elapsedMs`/`licenceMs`: execution
control updates bypassed the common meter recomputation after the Job had settled.

## Changes

- P&R inserts no DCAP and records `dcap_count = 0`; ordinary filler remains omitted.
- PG ring, stripes and `sroute` remain matched across both arms.
- The 0.85 placement/optimization target and above-100% physical-impossibility guards remain.
- Campaign budget is 12 hours, 15-minute closing reserve, 480 infrastructure actions and 8 generations.
- Effective stage timeout minima are 1 h for free/generation/layout/characterization/LC, 2 h for DC
  and verify, and 4 h per P&R arm.
- Failed P&R logs retain process exit, batch-error count, physical failure class and observed DRC marker total.
- Campaign execution updates use the existing `advance()` path so the last completed Job refreshes meters.
- Workshop instructions state the exact runtime proposal bound to prevent an avoidable first-attempt overflow.

## Validation boundary

The Pack's 137 domain tests, 26 held-out matched-flow contract cases, focused Campaign-control tests,
seal check, installation preparation and relocated Host smoke are the release gates. No commercial
EDA run is performed during publication. Trial.8 is retained as the real failure evidence; the next
Hima Campaign owns both-arm P&R, E0 iterations and the 5% Fmax goal.

Native release used zero-Job test Run `run-fa2905a5-041d-430f-9403-77b38df13b97` and wrote the
5.1.4 seal through the Harness release operation.
