depth anchor. Its depth-1 mixed-drive median was 12.25 ps while the foundry D1

- global delay scale is 0.95;

  template Cell;

- maximum capacitance is bounded by the foundry D1 envelope for the Cell input
  count, scaled by drive;
- the calibration report retains the selected D1 identity, anchor populations,
  drive ratios and maximum-capacitance envelope.
