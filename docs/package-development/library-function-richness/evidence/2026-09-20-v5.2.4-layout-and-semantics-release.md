# Custom Cell Fmax DTCO V5.2.4 layout and semantics release

Date: 2026-09-20
Version: `5.2.4`
Method digest: `aac74c25d1091e332983eb2a6592a1011afba502208c34c93afa44191894c098`

V5.2.4 combines two independent findings from trial.17:

1. The Mock Library layout stage repeated one Boolean topology placement for
   all five D1/D2/D4/D6/D8 variants and ran 250 physical Cells serially. The
   corrected stage places D1 once per family, reuses its column topology for the
   four scaled LEFs and executes up to five independent families concurrently.
2. `read-characterize` correctly emitted `cell_demand_count=50`, but the Pack's
   semantics and Reader manifest did not both declare that value. The Harness
   therefore auto-paused the otherwise successful Run. The Pack now declares
   the value in `semantics.yml` and `readers/read-characterize.yml`.

Claude preserved the exact trial.17 refusal and implemented the semantics fix
in `c0089dd`. Codex reproduced the undeclared-value failure on released 5.2.3,
reviewed the change, and added the missing Reader-manifest declaration after
the native Pack checker caught that second half of the contract.
