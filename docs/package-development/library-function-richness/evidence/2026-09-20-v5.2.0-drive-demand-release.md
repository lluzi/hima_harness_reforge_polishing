Trial.13 showed two systematic method defects: all requests declared drive
intent without materializing electrical variants, and Research programs could
read misspelled feedback fields through `dict.get` and silently obtain zero.
Critical paths also contained generated arcs around 40 ps, but no independent
calibration separated true topology weakness from model pessimism.

V5.2.0 retains the existing Campaign graph and upgrades its existing seams:

- `mine → generate → layout → characterize` now materializes one Boolean
  function as D1/D2/D4/D6/D8 with different SPICE widths, LEF sites, Liberty
  capacitance/area/max-load and output resistance;
- D1 delay uses transistor logic depth and P/N stack penalties anchored to the
  matching Site foundry CDL/Liberty at 20 ps / 3 fF; larger drives scale from
  D1, and one Pack-owned `global_delay_scale=0.85` is explicit;
- candidate pool and commercial feedback projections are typed; candidate
  programs cannot use `dict.get`; the runner records frozen-pool selection with
  and without the latest commercial response;
- every selected proposal becomes a Cell Demand containing pins, functions,
  truth table, required delay, endpoints, intervention and physical family;
  characterization stops before LC/E0 unless some drive meets every Demand.

Low-cost verification:

- Pack Python domain tests: `148/148` passed;
- Pack contract tests: `26/26` passed;
- flow/tools stage, reader and bind-input mirrors are byte-identical;
- real Site CDL/Liberty anchor extraction sampled 512 cells in 4.87 s and
  produced populated depth-1, 2, 3, 4 and 6 anchors; sparse slow specialty
  anchors are capped by the observed depth-1 delay times logic depth before the
  global scale is applied;
- one real five-drive calibration generated 5/5 Cells and accepted its Demand;
- Library Compiler T-2022.03 read the Library and wrote a nonempty DB;
- Design Compiler linked D1 and D8 without unresolved references and reported
  0.02 ns versus 0.01 ns arrival at the declared 20 ps / 3 fF check point;
- native publication Run `run-8be5fdbb-de0a-431a-8456-cc8824f7e57b`
  used no model or commercial Campaign Job.

A broader all-local run was also attempted but is not counted as a pass. It
encountered unrelated existing failures in the legacy AES synthetic PnR and a
Fabric restart permission fixture, then was stopped after the failures were
retained. The affected Pack-specific 26-test contract file was rerun separately
and passed 26/26.

The direct API JSON probe is retained only as negative test evidence: one call
spent its completion budget in reasoning, and later calls returned
contract-invalid or malformed JSON despite JSON mode. It does not represent the
product's coding-Agent Workshop path and is not counted as a model pass. The
Claude-operated v15 trial must validate the real DeepSeek Workshop feedback A/B
before matched P&R.

This release does not claim 5% Fmax or measured Cell characterization. It makes
the next Campaign's electrical and Research assumptions explicit and falsifiable.
