# Custom Cell Fmax DTCO V5.1.7 cross-generation Cell namespace release

Pack: `custom-cell-fmax-dtco`

Version: `5.1.7`

Trial.11 proved that generation 2 could read generation 1 and run the onsite
Workshop, then exposed four same-name/different-Cell collisions between the two
Library deltas. Pack 5.1.7 assigns the next immutable shard namespace to every
new candidate before generator, layout and characterization work. Physical Cell
names from different generations are therefore disjoint.

The cumulative manifest and augmented mapping Library independently reject any
remaining collision. This release does not claim that generation 2 reached E0
or that the AI's onsite strategy produced a QoR gain. The next Campaign owns
those results.
