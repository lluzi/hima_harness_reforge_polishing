## Consequential claims and rivals

| Judgment | Evidence | Strongest rival or limit | Decision effect |
| --- | --- | --- | --- |
| Library-only and placed-instance analyses answer different questions. | I1 abutment tests, independent I2 instance planning; I4 physical routing inputs | A carefully chosen library stress suite may screen many defects without a design. | Support both library screening and design-conditioned validation; do not require full-chip P&R for every first check. |
| Better detection can cost much more compute. | I1 original Table 3 | This historical Tcl implementation/runtime is not representative of all modern methods. | Measure detection coverage and runtime separately; stage cheap geometry before expensive routing. |
| Advanced-node architecture changes alter accessibility models. | I3 A16 relevance, I5 BSPDN, I6 M0/M1 gear ratio and offset | Backside PDN can alleviate frontside congestion rather than only worsen it. | Parameterize by actual stack/rules/architecture rather than infer all behavior from node name. |
