# 保留参考图，以回溯和附加研究扩展探索

用户在 Q17 明确：Pack 的参考运行图不能被 AI 修改或删除节点，AI 可以回退、改变节点策略，并在特定节点上生长新节点。这个取舍保留原有业务方法的完整性，同时为预算内的新研究提供空间。

策略改变后保留历史，复用仍有效的结果，重新运行受影响的下游，这是 Q18 已确认的语义。Q23 明确在 Pack 声明的探索位置使用已有节点语义生长附加研究，开始前说明影响节点和结束后的变化，声明输入、结束条件与返回位置。Q24 允许可选支路失败、取消或不采用并保留记录，但不能绕过当前结论必需的证据和检查。

本决定不推断所有新增工作都不影响原流程，也不授权新增架构组件。
