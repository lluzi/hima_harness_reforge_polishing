# 将运行知识资产归档在对应 Pack 内

用户在 Q26 确定：HimaPack 内有固定位置，归档这个 Pack 实际运行产生的知识资产。它承接技术报告、证据、数据、环境声明与算法等必要支持材料，使客户持有的方法与运行积累能够一起管理。

Q30 确认下一次研究主动使用与当前问题、设计和环境相关的资产，标明来源、适用条件与证据强度；历史知识是研究输入，当前结论仍需当前试验验证。Q31 确认自动归档和提出改进，但参考方法升级须由 Pack 所有者或授权作者确认并形成新版本，追加资产不悄悄改变默认方法。

Q32 确认同一客户升级时保留资产，自身 Pack 迁移时可以携带；向其他客户或公共来源交付参考 Pack 时不默认包含客户输入、结果或专有算法，分享内容由客户明确选择。目录命名、复制逻辑及与现有 Experience 的衔接由实现验证决定，不据此新增知识库组件。
