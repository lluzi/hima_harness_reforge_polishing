# DSH 权限层级不绕过 Site Permit 和删除红线

用户于 2026-09-14 决定：HimaHarness 复用 DeepSeek Harness 的 session permission presets、sandbox、approval 和 credentials，为本机 Agent 提供 Observe、Standard 和 Full 等权限体验；即使选择最高权限，Campaign 操作仍须通过现有 Site Permit、Pack wrapper、Channel verb、资源和删除红线。两层约束表达不同事实，不能互相生成或覆盖；需要 Permit 外操作时可由用户在普通 Coding 环境明确执行，但不因此成为受控 Campaign 证据。
