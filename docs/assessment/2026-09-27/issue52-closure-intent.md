## Team method

The Pack owns one `timing-eco-team` recipe. Runtime materializes dynamic Run, node, execution,
Ledger, Site and binding identities.

1. **Researcher** reads current closure state and experience and returns bounded action hypotheses.
2. **Reviewer** reads the exact Researcher result, current evidence and reader-backed fix plan, then
   returns exactly one reviewed action bound to the plan SHA-256.
3. The **Run owner** adopts that exact Reviewer result.
4. **Operator** is admitted only after adoption, receives one immutable typed action inline, has only
   `hima_interactive`, and performs one validate/mutate/verify/save/finalize/close transaction.
5. The **Run owner** adopts the exact Operator result and completes the node from finalized evidence.

One role has one deterministic child identity for one Run/node/execution. Retry reuses that child
when still valid. A second Operator for the same execution is refused. Child output never changes
Run state until owner adoption.
