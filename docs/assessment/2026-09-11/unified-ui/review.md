# UI-02 独立双轴审查

比较基线：`e994087133ffd2f0bf1dcc79f611b4f70a1d3ac5`。审查对象为本轮工作区差异和新增客户端文件；规格为 GitHub #21。审查者均只读，没有执行窗口或替主代理确认实测。

## Standards

最初发现：

- P1：Resume 请求等待整段恢复执行，所有控制随之 disabled，导致用户不能取消长 Job。
- P2：加载/校验失败也显示原字节验证通过。
- P2：准备检查失败清空选项，用户只能重开表单，丢失草稿。

第一次修正后发现：

- P2：A→B→A 后原 action busy 仍在，已中止请求无法清理它。
- P2：提交期间外层 Run 选择可卸载表单，丢失 Host 开始操作的结果身份。

最终复审：无剩余阻塞项。共享 `useRunActions` 重置身份状态，并允许 Cancel 替换 pending Resume；开始期间的导航受同步 ref 与界面禁用保护；准备失败可保留草稿重试；验证声明仅成功后出现。对话卡片明确为快照，详细数据从 Live Run 阅读。

## Spec

最初发现三项 P2：报告验证声明不实、预算未完整展示、证据面板缺少判定原因/规则版本/引用及拒绝路径。

最终复审通过。预算复用 `meterRows(view)`；EvidenceTrail 保留 VerdictRow、DecisionRow、拒绝路径、阻塞日志/元信息及取消记录；已保存文件声明按实际读取结果显示。未发现新架构组件或额外业务范围。

两轴最初分别 3 项、3 项；Standards 跟进另发现 2 项。最终阻塞项均为 0。窗口行为以主代理实际用例与日志为准。
