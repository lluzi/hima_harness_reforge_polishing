# HimaHarness 中文全景演示脚本

视频按照以下叙事展开：

1. **产品定位**：一个工程师、一个持续运行的 Campaign Agent、一套方法 Pack、多个商业 EDA 工具，
   由 Fabric 和 Ledger 连接成可恢复、可审计的研究闭环。
2. **完整用户旅程**：启动 → 中文对话 → Pack/Site/输入检查 → Campaign 提案 → 唯一 Run → 节点执行
   → 暂停/恢复 → 代码与证据 → 报告与资产。
3. **DTCO Pack**：Information Graph、Cell Demand、F0–F3、累计 Library、matched E0 和跨代反馈；
   用 Trial 24 说明研究机制在改善、商业目标仍未达到。
4. **Timing Closure Pack**：Innovus、XTop、StarRC、PrimeTime 独立节点；endpoint 集合反馈、保留布线
   的 ECO、best database retention；用 Trial 30 说明连续八代真实改善。
5. **价值收束**：Harness 不替代单点 EDA 算法，而是把多工具、多迭代、长周期、容易中断的芯片研究
   变成一个可交付、可继续和可积累经验的工程系统。

逐场景完整旁白与来源在 `manifest.json`，精确时间轴在 SRT 文件中。
