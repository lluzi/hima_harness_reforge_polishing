## 修改内容

1. 指定一位没有参与本轮候选实现的独立 Agent，以工程师视角，在完成一次 Site 准备后，通过桌面和对话选择 Pack、提供输入、开始、介入并读取结果。
2. 开发者提供一次性部署与输入准备，随后由审阅 Agent 独立操作并记录卡点；不得用后台代执行冒充 UI 操作，不得将 Agent 记录称为真人认可。录制只包含 Catsights 上的本产品测试窗口。
3. 记录提问、卡点、错误提示、研究结论理解和知识资产可取得性；问题按最小可复现模块拆修，必要时重验受影响路径。

## 验收标准

- [x] 被测 commit/Pack 版本/环境/预算明确；操作由指定独立 Agent 完成，有屏幕录像、操作记录及其审阅结论。
- [x] 无需日常编译源码或手改内部 YAML；准备阶段与日常使用分开记录。
- [x] 审阅 Agent 能从产品界面区分执行成功、指标未达标、有效负结果与未验证内容，并能取得报告/算法及证据。
- [x] 按用户授权，独立 Agent 可根据完整操作证据给出通过/失败并建议关单；未完成操作或录制则不算通过。用户真人试用和研究价值认可仍待后续反馈。
