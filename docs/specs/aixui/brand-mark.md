# aiX 品牌字标与 X 比例规范

状态：2026-10-15 用户反馈落实到本地 aixui 候选，尚未提交或合入。此规范针对品牌 X，不改变关闭、取消等功能图标。

## 基准与比例

品牌字母使用 **Urbanist 500**，界面正文继续使用 Manrope。以 Urbanist 500 的小写 i 竖笔画宽度为 **t**。字体实测 em=2000，竖笔画宽 167.998046875，含圆点的 i 墨迹高度 1345.4241333007812。

| 元素 | 约定 |
| --- | --- |
| i 竖笔画 t | 0.083999 em |
| X 每一斜线的垂直厚度 | 1t；沿斜线法向量测量，不按水平截面量宽 |
| X 斜线角度 | ±45°，四段完全对称 |
| 中央核心菱形留白 | 水平、竖直对角线均为 2t；由四个内端切面的延长线界定 |
| 同一斜线上两个内端切面的法向间隔 | √2t |
| X 可见高度 | 与含圆点的 i 墨迹高度相同，约 0.672712 em |
| 顶部与底部 | X 墨迹顶端对齐 i 圆点顶端，底端对齐文字基线 |
| i 与 X 的横向墨迹边界间距 | 1t；包含字体侧边距和 SVG 视框内边距后的总间距 |
| 缩放 | 所有品牌席位使用同一几何定义等比缩放；不为浅色、深色或尺寸单独拉伸/拼图 |

在 24×24 视框上，可见高度为 21，笔画 t=2.62219095，中央菱形对角线 5.24438190。中心核心留白约为可见高度的 25%，比上一版明显收紧。四个内端仍保留间隔，整体轮廓保持可辨识的 X。

## 唯一来源

- `packages/harness/src/client/aix-symbol.ts` 定义几何与比例。
- `AiXSymbol` 为主字标、侧栏字标、展开/收起导航提供同一组图形。
- `packages/desktop/scripts/make-icon.mjs` 直接消费同一几何并生成 PNG/ICNS 及启动页内联 SVG。
- `aix-style.ts` 只负责字体和等比排版；不引入另一套主题状态。X 视框边距补偿使实际墨迹按基线对齐。
- `assets/fonts/Urbanist.woff2` 由 Google Fonts 官方 Urbanist 变量字体转为 WOFF2，字标固定使用 500；SIL OFL 1.1 完整文本保留在 `Urbanist-OFL.txt`。

## 真实渲染证据

64 px 字标：i 竖笔画约 5.376 px；X 斜线约 5.376 px；中央核心菱形对角线按约定为 10.752 px；i–X 实测间距约 5.352 px；基线误差约 0.000061 px。允许浏览器的像素取整，不改变源几何比例。

## 单行母品牌与产品字标（2026-10-15 用户修订）

侧栏、启动/错误页使用 **Empyrean → aiX → Harness** 单行组合，不换行。产品文字统一为 Urbanist 500；界面正文继续使用 Manrope。

以字号 em 为单位，公司英文图宽 5.37em；采用原图 y=70 的文字光学基线，补偿图框下移 .216242em，使公司英文大写字面与 i 含圆点墨迹高度接近。母品牌与产品间距 .625em，产品 aiX 与 Harness 间距 .375em。原公司图形、裁切区域和 X 几何保持。

展开侧栏始终省去最左侧重复的独立 X，只显示 Empyrean 与 aiX Harness 单行组合。组合在原生按钮容器内按 12–16 px 缩放，按钮最小高度 24 px；收起导航仍使用独立应用图标。启动页同样去掉前置应用图块，字号为 16–24 px，保留 40 px 的最小行高，字面与间距按同一比例缩放。
