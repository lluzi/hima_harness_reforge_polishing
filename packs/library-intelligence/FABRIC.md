# Qualification execution

The default graph starts at `qualify-api`. Fabric uses its existing `beforeLaunch` callback, after ordinary Permit/workspace resolution and inside the serialized Site slot claim, to attest the exact Host-loaded Permit and the Site-bound manifest. The Host authorizes the manifest, Permit, sources, Site-bound Python, API paths, wrapper spelling and resolved wrapper target; pins the Python and `/usr/local/bin/edarun` bytes; checks the private Campaign workspace; and writes the admitted run/node/attempt/Job-session identity at the exact workspace attestation path. That file carries the launch identity to the worker and Reader; it is not the trust root by itself. Before a positive Reader value becomes an observation, Fabric matches the identity to a successfully finished qualification Job in the same Run. Authority remains the Host `beforeLaunch` decision and durable Job history. The Reader uses `/usr/bin/python3`. The Pack never changes an original source, vendor installation, license service or published method. A blocked or absent receipt cannot open later Library facts work.

A later attempt may replace a pre-dispatch attestation only for the same Run and node with a strictly greater attempt. Once `flow/qualification` exists, in-place retry is refused because the worker's create-once evidence cannot be safely reused or overwritten; start a new Campaign workspace after reviewing the failed evidence.

The tool holds the exact `QuaLib-2026-new-59099` Site licence claim. E1 requires `capacity.parallelJobs: 1`; the existing serialized Job cap therefore prevents both overlap orders with XTop **for Jobs launched and tracked by this Hima Host**, without recording a false XTop seat on a Library Job. It does not detect an external process. This is intentionally broader than an Empyrean-only mutex and matches the qualified Site policy. A future multi-Job Site needs a truthful shared runtime-selection claim declared by both tools before it can host this E1 method. Do not treat E1 qualification as E2 facts or product release approval.
