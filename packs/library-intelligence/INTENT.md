# Library Intelligence qualification (development)

This development Pack holds the E1 method and one Host-attested QuaLib qualification tool for exactly three bounded inputs: a vendor fixture, one SAED14 representative, and one TSMC28 representative. Its default graph can enter the native qualification only after the Host proves the loaded Site Permit identity, every nested read path, the private workspace, the pinned `edarun` bytes and the QuaLib 2026 new/59099 claim at the final prelaunch boundary. The Pack does not scan a corpus, produce Library facts or a design-impact report, or authorize a Library edit.

The Site owner provides the input manifest, qualified Python and Permit through the existing Site bindings. The Host writes `hima-library-host-attestation.json` only after all launch checks pass. The worker binds that record, reads, queries, copies only within the Campaign workspace, re-reads, compares, and re-hashes each source. A native failure remains blocked with no partial facts. E1 eligibility does not qualify a wider corpus or complete E2-E4.
