# Case recipe

No case recipe is installed with this copy of the Pack. A Site that has run this Pack on a case
before may install one here: the proven move sequence for that case, written from its earlier
Runs' judged history, naming the case by its manifest `caseId`.

When this file names the Run's case (`state/case-readiness.json` → `manifest.caseId`), follow it
round by round before the generic fast path; every number in it was judged on that case. When it
names another case, or none, as here, use the playbooks' generic guidance.
