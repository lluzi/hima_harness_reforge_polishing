# Empyrean corporate mark

User-selected reference: https://en.wikipedia.org/wiki/Empyrean_Technology

Original artwork: https://upload.wikimedia.org/wikipedia/en/8/8d/Empyrean_Technology.png

File description: https://en.wikipedia.org/wiki/File:Empyrean_Technology.png

The 490×203 PNG is retained byte for byte. It contains the English corporate mark above the Chinese name. Its English ink bounds are x=25..469 and y=0..87; the Chinese row begins at y=103. The UI displays a viewport x=24, y=0, width=447, height=88, retaining the English symbol and lettering in their original proportions. No font approximation or AI redraw is used. The light theme keeps the original blue; the dark theme displays a white monochrome silhouette through a CSS filter, preserving alpha and geometry.

This is Empyrean's corporate logo, not an OFL-licensed font asset. The source identifies it as a non-free corporate mark; rights remain with its owner. Its inclusion follows the user's explicit brand direction and does not assert a new license over the mark.

Run `node packages/harness/scripts/make-brand-assets.mjs` from the checkout to regenerate the client data URL and identical desktop asset. It also refreshes the desktop Urbanist font and its OFL from the shared font assets. Run `node packages/desktop/scripts/make-icon.mjs` for the canonical startup X SVG. All are offline assets, with no fetch at runtime.
