# End honestly, and in more than one way

A Campaign ends in facts. There are exactly three honest ways for one to end, and a generation limit
is not among them.

1. **The Goal is met.** The target was reached and the constraints hold, stated with the values and
   the citations that say so.
2. **The exploration converged.** The moves stopped changing anything: the value the Loop converges
   on stayed inside the declared band across the declared number of generations. "Converged" is a
   measurement, not a mood — the pack declares which value and which band.
3. **An ending the pack declares in its own words.** Something in the business said stop, and the
   pack said in advance what that would be: a gate the library tool refuses to pass, adoption that
   stayed at zero, an input the flow rejects, a stage that cannot run on this Site at all.

**A generation limit is a budget, not an ending.** When a Campaign stops because it ran out of
generations, nobody knows what happened: the method may have been converging slowly, or it may have
been walking away from the answer for its whole life. An ending nobody can explain is the one thing a
Campaign must not deliver, because the whole promise is that it ends in facts.

## What this means for a pack you are authoring

- **Write the `Endings` section first, not last.** Every way this business can stop, in the words a
  person would use. If you cannot name three, you do not yet know the business well enough to author
  the pack.
- **Every declared ending needs the value that detects it.** An ending that no reader produces a
  number for is an ending the runner can never reach. If the pack says "stop when the library gate
  fails", some reader has to report whether the gate failed.
- **Convergence is stated in the chooser's own vocabulary.** The value converged on has to be one
  the chooser actually reads; a pack that converges on a number its chooser never looks at can only
  ever end at its limit.
- **The generation limit stays, and stays a budget.** It protects the Site and the person's time. It
  should be reached only when something is wrong, and when it is reached the report says so plainly
  rather than dressing it up as a conclusion.
- **Say what a person must never have to guess.** If a stop can be read two ways — met exactly, or
  not measured at all — the pack's words must distinguish them on every face.

## Citing it

When this file shaped a decision, cite it by name and say what it changed — "made every ending one
this pack declares in words, and added the reader that detects the library gate's refusal".
