# Task 2：设计首版客户试用

文档 ID：D3D-T2；版本：1.0。

### T2-01｜新的业务目标

同一虚构项目“叠衡 Sketch”、同一团队现在需要一份首次客户试用方案，给岚汀计算的架构师和封装同事一起使用。请从新上下文开始，设计开场说明、客户准备项、操作步骤、交付物、成功/失败判据以及出现缺项时的处理话术。重点是让客户知道试用结束后可以作出什么决定和下一步由谁负责。本任务不再编写研发 functional spec，不运行真实 EDA。

### T2-02｜本次约束

客户可提供两个不同划分的候选、带版本的模块与通信 CSV、功耗区间和一份封装外形草图；冷却条件尚待客户补充，详细实现数据库当前不可提供。这些都是虚构试用条件。请给出当场可做和需等待的动作、未知如何呈现，以及客户如何复核交付。时间盒由操作员在任务创建时给出，不要求为了演示速度宣称正确或通过签核。

### T2-03｜历史决定与范围

使用产品提供的获准记忆查询，主动调查本项目/本团队已经采用、仍有效的业务决定及其条件，记录实际使用的来源与版本。没有可用经验或来源不能核对时，明确说明缺项并提出最少必要问题；不要凭猜测填入内部约定。本次不附上一任务 transcript、规格或人类反馈。提出的试用流程必须独立可执行，引用所用决定，解释它如何改变步骤或成功判据。
