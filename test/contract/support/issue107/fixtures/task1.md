# Task 1：给首版定位形成可研发的规格

文档 ID：D3D-T1；版本：1.0。

### T1-01｜目标与材料

我们在虚构项目“叠衡 Sketch”中，需要决定面向 3DIC 的 EDA 工具首版定位。请混编团队只依据所附 D3D-A@0.8 与 D3D-B@0.9 两份中文资料调查分歧，提出必要问题并形成能指导研发的 functional spec。资料内容都是 demo 设定，不能当作真实市场、工具或芯片事实。可否决建议，不能为了完成文档而编造支持证据。

### T1-02｜工作方式与交付

请分工核对原件，研究业务价值、输入可得性和交接风险，安排反证者检查推理，再由编辑整合。至少明确一处不能按日期或版本号自动解决的冲突，向有权决定的人提出具体问题；未答复则保留条件分支及受阻项。说明哪些是场景记录、提案、假设、缺证据，引用文档 ID、版本和段落 locator。不要将 unknown 改写为零或通过。

规格应能让研发判断价值与影响、用户操作和状态、数据/接口与版本、异常处理、非目标、来源、分歧处置以及可执行正反验收。形式可自定；每个关键行为须有理由和能够推翻它的实例。数量、篇幅或模板齐全不能替代判断质量。保留首版成果、问题、实际人类回答和修订历史，最终说明未验证范围。不要运行 EDA、查真实市场或承诺 signoff。
