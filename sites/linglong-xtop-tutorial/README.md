# linglong-xtop-tutorial

An ATCS Site on linglong for the design that ships inside ICExplorer-XTop 2025.09 itself:
`share/tutorial/input_files` of the install, copied unchanged (all files read-only) into
`/data/eda/project/hima_harness/xtop-tutorial/inputs/`. The vendor built this case to show XTop's
fixing commands, and it carries no foundry data.

| Item | Value |
| --- | --- |
| Design | `cpu`, 3,922 cells, netlist + DEF (`design/cpu.v.gz`, `design/cpu.def.gz`) |
| Scenarios | `func_slow`, `func_fast`, `test_slow`, `test_fast` (modes func/test × corners slow/fast) |
| Libraries | `.idb` per corner (`lib/slow`, `lib/fast`); tech LEF `lef/tech/tutorial.lef`, cell LEFs `lef/cells/*.lef` |
| Timing data | the vendor's PrimeTime dump `sta_data/` (4 scenarios); constraints exist only inside it |
| Starting violations | setup 1,029 / WNS −4.0744 ns / TNS −1535.998; hold 906 / WNS −3.3884 / TNS −256.916 |

The inputs are an **XTop-native** design state (`inputKind: xtop-native`): no Innovus database, SPEF or
SDC. The native timing context declares `constraintsEmbeddedIn: staData`, so the constraint identity
is the dump's tree digest. Every timing number on this Site is XTop's own incremental GBA timing on
that dump. It is prediction-only: there is no PrimeTime refresh, extraction or physical signoff here.

## Files

- `site.yml` / `permit.yml`: Site and Permit (write root `xtop-tutorial/runs` only).
- `engineering-capabilities-xtop-tutorial-v1.json`: the resident sandbox capability, installed at
  `operator-admin/resident-engineering-v1/` (mode 0444, SHA-256
  `4491e885cd872a9b7d776168c3fcfb6615c1b0f5718f093e1431d7c9a117f805`). It is the 28 nm capability
  with read roots narrowed to the tutorial inputs; same wrapper, image and OpenCode.

Input documents in `inputs/` (mode 0444), generated by `xtop-tutorial/tools/mkinputs.py` with the
Pack's own `atcs.core` digests:
`designStateManifest-xtop-tutorial-v1.json`, `siteCapabilities-xtop-tutorial-v1.json`,
`nativeTimingContext-xtop-tutorial-v1.json`.

## Seam proof (2026-10-07)

`task-prepare-inputs` and `task-prepare-baseline` of ATCS 0.4.1 (working tree) ran on these inputs in
`runs/dry-01` with real XTop (25 s). The staged "before" equals the vendor tutorial's own
pre-optimisation report exactly; the common R1 AutoFix left setup 615 / −1.9254 / −624.1548 and hold
372 / −3.0570 / −61.9808.
